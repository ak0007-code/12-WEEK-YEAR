# Health

心と身体の健康に関する目標、気づき、計画、実行記録を管理するディレクトリです。
「食事」「運動」「睡眠」「美容」の4つのサブセクションで管理します。

## サブセクション

### 食事

栄養バランス、間食・飲み物のコントロールなど、食習慣に関する方針と実践を扱う。

- 現在の方針：お菓子・アイス・ジュース・揚げ物を断つ（週1回だけ解禁可）。毎日のヤクルト1本と果物は許容する。

### 運動

日々の運動習慣と身体づくりを扱う。

- 現在の方針：週4回の運動を継続する。

### 睡眠

睡眠の質と、それを支える夜のリズム・休息を扱う。

- 現在の方針：21時以降は仕事をしない。22時までにお風呂を上がる。Apple Watchで睡眠スコアをチェックする。

### 美容

肌・見た目のケアを扱う。

- 現在の方針：週2回の顔チェックを継続する。

## 構成

- [`INSIGHT.md`](INSIGHT.md)：ユーザーが明示した重要な気づき（サブセクション別に整理）
- [`details/`](details/)：相談、調査、実践、振り返りの詳細

週ごとの具体的なアクションと実行記録は、ルートのREADMEおよび `plans/` を正本とします。
