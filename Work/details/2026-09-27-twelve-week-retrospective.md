## AI

Cycle 1の仕事を、英語と同じ「目標 → 行動 → 成果 → 未来への活用」の順で振り返った。

目標：

- ビジョン：「Ampliumに必要な機能が揃い、AI研究も前進している」
- 戦術：14時までに図書館でAIの勉強を始める、21時までに仕事を終える、Jiraで週ごとにチケットを決めて消化する

行動：

| 時期 | 仕事のアクション | 実行 |
| --- | --- | --- |
| W1〜W4 | 2時までに仕事を始める | W1は2/4、W2〜W4は毎週5/5 |
| W5〜W7、W9 | なし | — |
| W8 | Finance/BizDevに1時間以上かける | 5/4 |
| W10〜W11 | 終業メモ・始業プランニング（各5回） | W10は4/5、W11は5/5 |
| W12 | 同上 | 1/5・0/5 |

- 健康側の「21時以降は仕事をしない」は、85%を満たした週が11週中4週
- 計画の外では、W9に意図的に英語より事業戦略を優先し、金曜の夜と土曜が仕事で埋まった。8/30のメモでは、深夜2時まで続ける日が続いていた

成果：

- 前半：チケット全消化（W4・W7）、AI研究のコースも予定どおり進んだ。W4までに、今あるプロダクトの残要件はほとんど済んだ
- 後半：Amplium-MacのSBS対応を本番展開した。インスタでAIを使った流れでフォロワーを獲得できた。AI広告動画と受託エンコードの需要検証を始めた
- ただし売上はまだ立っていない（W9時点）。仕事の結果指標は、W5「ファイナンスと売上戦略ができている」未達、W8は空欄、W10「成果物を出し切る」未達、W11は成果物を決めず、W12未達

見えたこと：

1. ビジョンが小さく、作る側の完了条件になっていた。機能はW4でほぼ揃い、本当のボトルネックだった売上・マネタイズはビジョンに書かれていなかった。後半の8週間は、一番重い仕事をゴールなしで進めていた
2. 測れる仕事は達成し、測れない仕事は計画から消えた。チケットやコースの週のように先に決められるものは毎回達成した。形が決まらない事業戦略は未達か空欄で、W5〜7とW9はアクション自体がなかった。アクションを書いた週の実行率は高いので、崩れたのは実行ではなく計画の側
3. 始まりは守れて、終わりが守れない。14時の開始は記録したW2〜W4で15/15。21時の終了は4/11週。市場検証のように答えが出ない仕事は、終業メモを書いても頭の中で閉じない（W11の分析）
4. W12で記録が止まった理由は「仕事でやりたいことがあった」。計画が仕事に割り当てた量と、仕事が実際に求めた量がずれていたサインとも読める

未来への活用（案）：

- ビジョンは「作る」ではなく「市場の反応」で書く。`10YEARS.md` では31歳が「ビジネスが軌道に乗りマネタイズ出来ている」なので、そこにつなげる
- 結果を自分で決められない仕事は、指標を2層にする。自分でコントロールできる検証の本数（先行指標）と、支払意思や売上などの市場の反応（遅行指標）。W7・W11に自分で書いていた「9/10は外れる」「桁が違うくらいトライする」を、そのまま指標にする形。The Right Itのpretotypeや、英語で置いたxyz仮説と同じ考え方
- 仕事のアクションが空になる週を作らない。仕事を優先する週は、計画にそう書く
- 1日の仕事を「その日の成果物」で閉じ、健康の「21時の終業の儀式」とセットにする
