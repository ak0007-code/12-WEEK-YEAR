# 自分の理解できる単語とフレーズを増やすということ

- 自分が英語を理解できない時はそもそも単語とフレーズを知らないことが多い
- そのため、ここに力を入れることが英語力を向上させるエッセンスの可能性が高い
- 単語帳を勉強するのではなく、PodTextで分からなかった英語を可視化して、それをRepeatifyで毎日振り返る
- 知っている英語が増えていったら、論理的には分からないことの方が難しくなる状態になるはず

# Actions(効果のあったアクション)

- **自分の実会話の録音 → 文字起こし → 何回も聞き返し・真似する**(オンライン・オフライン問わず。ローカルのネイティブとのオフライン会話がより好ましい)。聞き取れなかった英語が文字で答え合わせでき、自分の英語のまずさ(ぶつぶつしたテンポ等)にも客観的に気づける

# 発声・発音

- 口先ではなく喉の奥で低く発声する(力で下げず、喉を開いた結果として低くなる)
- 子音と母音を分離する。フレーズ最初の子音をツッコミ気味に引っ張って入る
- 内容語にストレスを置き、機能語は曖昧に発音する(ストレスは強さより長さで出す)
- フレーズ末はガラガラ声(ボーカルフライ)が出るボトムエリアに着地する
