### 4. おすすめの使い方と今週のリスニングテスト

**今週の最初のリスニング模試に最適な無料テスト**：Free CELPIP-General Practice Tests (Starter Set) の **Practice Test A** の「Listening」のみ。理由は、公式・本番と同じ6パート38問・即時採点・台本付き・換算表付きで、Test Bを後日の進捗確認用に残せるからです。

**本番に近い条件で受ける手順**
1. celpip.ca の Free Practice Tests ページでフォームを送信し、Starter Set を開く（PCまたはタブレット、ヘッドホン、静かな部屋、紙とペン）。
2. Practice Test A を開き、ドロップダウンで「Listening」を選ぶ。
3. 本番ルールを自分で守る：音声は **1回だけ**（再生バーで巻き戻さない）、NEXTを押したら **戻らない**、Part 1〜3は1問30秒以内、パート時間の目安は 8・5・6・5・9・8分。スマホのタイマーで計り、途中で止めない（合計約50分）。
4. 終了後「Your Score」で正答数を見て、上の換算表でレベルの目安を出す（例：CLB 7が目標なら27〜31問、CLB 9なら33〜35問）。
5. 翌日、「Practice Test A Listening Transcripts」で間違えた問題をパート別に分析し、台本を見ながら聞き直す→見ずに聞く→シャドーイング。

**1〜4週間の進め方（自習者向け）**

| 時期 | やること |
|---|---|
| 今週 | Listening Pro Study Pack 2026（PDF）で形式を確認（30分）→ Test A Listening を本番条件で受験 → 台本で復習 |
| 毎日（20〜30分） | 台本で復習、Podcast #21、CELPIP in 5 Minutes a Day。Part 5・6（議論・意見）の語彙を重点的に |
| 今週〜来週 | Listening Pro ウェビナーの録画をYouTubeで視聴、または11/21・11/23のライブに登録 |
| 1〜2週間後 | Test B Listening を同じ条件で受験し、正答数の変化を確認 |
| さらに必要なら | LS Starter Set（Listening 2回分、General版と同内容かは未確認）→ 有料Practice Test（Set 13など）、Accelerate LS（$25 CAD）、Study Guide LS |
| 本試験の2〜3週間前 | Practice Test を1回分、全技能を通しで（2時間39分）受ける |

頻度の目安：時間を計った完全なリスニング模試は1〜2週間に1回、間は毎日の短い復習に充てる（模試を使い切らないため）。
