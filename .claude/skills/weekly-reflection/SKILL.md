# 週次の振り返り開始

README.md の今週分を `## Planning & Reflections` へ移し、振り返りを書ける状態にする。`N` は `plans/` で `status` が `active` の週番号。

## 1. 最新化

1. `git fetch` して、origin/main より遅れていれば pull する。
2. 手元に未コミットの変更があると、sync-worker が更新した表と衝突しやすい。
   - `git stash` → `git pull --ff-only` → `git stash pop`。
   - `## 今週のアクション` の表が衝突したら、表はリモート（sync-worker の最新チェック状態）を採用する。手元の表の変更は整形だけのことが多い。
   - 表以外の手元の変更（結果指標の書き込みなど）は必ず再適用する。消える前に `git diff README.md` をスクラッチパッドへ保存しておく。

## 2. 結果指標を判定する

- アクション実績は `plans/week-NN.json` の `completedDays` と README の表を正とする。
- 各アクションは `ceil(目標回数 × 0.85)` 回以上で達成。たとえば 7回→6回、5回→5回、4回→4回、3回→3回。
- 「アクション指標全て達成」は、その分野のアクションが全部達成なら達成。未達なら `未達（項目名 実績/目標、…）` と未達の項目だけ書く。
- 英語のテストスコアなど、ユーザーがすでに `：未計測` `：未達（26/38）` のように書き込んでいたらそのまま使う。分からない数値は推測せず、ユーザーに聞くか `：確認中` にする。
- この85%ルールは README には書かない。

## 3. Week N のブロックを作る

`## Planning & Reflections` の直下（前の週より上）に、次の形で挿入する。見出しの深さは既存の週に合わせる。

```markdown
### Week N

##### 結果指標

- 英語
  - <指標>：<結果>
- 心体
  - アクション指標全て達成：<結果>
- 人間性
  - アクション指標全て達成：<結果>

##### 方針

###### 全体

<今週のプランの「### 全体」の中身>

###### 英語

<今週のプランの「### 英語」→「#### プラン」の中身>

###### 心体

<「### 心体」→「#### プラン」の中身>

###### 人間性

<「### 人間性」→「#### プラン」の中身>

#### アクション実績

<今週のアクションの表をそのまま>

#### 振り返り

##### 英語

- Positive
- Insight

##### 心体

- Positive
- Insight

##### 人間性

- 崩れた日の数：
- そのとき起きていたこと：
```

- 今週のプランにある分野（仕事など）が増減していたら、その週の構成に合わせて結果指標と方針の分野も増減する。
- 内容は書き換えず、そのまま移す。

## 4. 元の場所を空にする

- `## 今週のプラン`：中身を消して見出しだけ残す。
- `## 今週のアクション`：表と `### Week N` を消して見出しだけ残す。消す前に、表が Week N のアクション実績と同じであることを確認する。
  - sync-worker は `## 今週のアクション` から `## 全体戦略` の直前までを置き換えるだけなので、2つの見出しが残っていれば同期は壊れない。
  - `week-NN.json` はまだ `active` のままにする。週の切り替えは次の週のアクションを決めてから行う（CLAUDE.md の「週の切り替え」）。

## 5. 日程にチェックを付ける

`## 全体戦略` → `### 日程` の `- [ ] Week N : ...` を `- [x]` にする。

## 6. コミットしてプッシュ

- 1コミットにまとめてよい。例：`Week Nのプランとアクション実績をPlanning & Reflectionsに移動`
- コミットしたら main へプッシュする（CLAUDE.md の「Gitの運用」）。

## 7. ユーザーに伝えること

- 移動した内容と、結果指標の判定（未達の項目と回数）を短く伝える。
- 注意点：今週の項目にまだチェックを付けると、sync-worker が `## 今週のアクション` に Week N の表をまた作る。そのときアクション実績の表は自動更新されないので、付け終わったら言ってもらい、アクション実績を直す。
- 振り返りの質問をする：
  - 英語・心体で良かったこと（Positive）と気づいたこと（Insight）
  - 「今週、人間性が崩れた場面はあったか」「そのとき何が起きていたか」
- 答えをもらったら `#### 振り返り` に書き込み、会話は CLAUDE.md の「AIとの会話記録」に従って `conversations/` などに記録する。
