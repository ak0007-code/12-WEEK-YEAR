# 人間性

> Source: [Notion](https://app.notion.com/p/394fae8ed03580029dcae84673aa8ca1)

## 目指すべき人間性

- 誠実である
- もの応じしない
- 一貫性のある言動を取る
- 意味理解力と意味伝達力が高い = コミュニケーション能力が高い
  - 日本語だけでなく英語でも実行できるようにする
  - 常に謙虚に、相手Firstのコミュニケーションをする
- どんな人にも同じ態度で接する
- ウソをつかない
- 近くの人ほど大切にする
- 人の意見を簡単に否定しない
- Give First の精神で、最終的に「Win-Win」になれるよう人と関わる
- 人を表面的な、性別・見た目・年齢・国籍・数回の会話から、良い意味・悪い意味の両方で、区別・判断しない
  - 人を表面的な薄い情報で区別・判断すると、
  - 短期的な利益に目を取られ、
  - 長期的に意味のある関係性に繋がらないことが多い
- 外部環境に対してリアクションを取らない / 外部環境の責任にしない
- いつも機嫌が良い
  - イライラしている時ほど自分を客観視する
  - AI時代にこの感情的な健やかさとEQはすごく大事
  - 「機嫌が悪いけど知的作業（プログラミング等）が上手い」というのはAIに代替されやすい能力であり、新しい時代に逆行する態度
- 衝動的に行動しない

## If - Then ルール

- もし同僚に対して、強い口調や雑なコミュニケーションを取っていたら
  - 一旦、頭を冷静にして、落ち着いた口調でコミュニケーションを取る
- もし相手のメッセージに対して、返信が遅くなったり、雑なコミュニケーションを取っていたら
  - 「返信遅くてごめん」と謝ったり、自分から予定や話題を提案したりする
- もしプライベートの相手とのコミュニケーションで、自分が機嫌が悪くなっていたり、相手の話に興味の無いそぶりを出していたら
  - 深呼吸して、「仕事モード」ではなく、「遊びモード」でその場の人生を楽しむ
  - 仕事を遊びに持ち込まない
