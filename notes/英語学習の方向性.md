# 海外滞在で英語が伸びる人の特徴を調べた研究

# 地域社会との交流

- 海外滞在は平均するとかなり有利だが、その結果は、正確さや細部の発達は自動ではない

特に「総合力」と「話す流暢さ」に出やすく

- 現地社会との意味のあるつながりが英語力を特に高める
- これは単純に入力が多いか少ないかだけでなく、その人が、その社会にどう入り込めるか
- それは、気合いや性格だけでなく、「相手との関係性」・「場へのアクセス」・「歓迎され方」にも左右される
- 最も伸びたのは、ネイティブ学生とも、留学生とも、複数の場でローカル言語中心の関係を持つ統合型だった
- 大事なのは現地人の人数ではなく、自分の濃い日常ネットワークで、どの言語が、どれだけ、どんな関係の中で使われているか
- 例えば、現地人と話していても、いつも表面的な会話だけなら効果は弱いことがあるし、逆に留学仲間中心でも、その中で目標言語が日常言語として回っていれば、かなり伸びうる

# 自習と地位交流のバランス

- 研究では「現地に住むこと」だけでは足りず、特に話す力・口頭運用力では、現地での意味ある対人交流のほうが、自習だけより重要という方向にかなり傾いている
- ただし、これは「自習 vs 交流」の二択ではなく、社会関係・動機づけ・授業・事前力が絡むSocial Ecosystemとして見ている
- 学生がうまく現地で交流できないと、それを追加の一人勉強で埋め合わせしようとしがちで、滞在先の学習機会を十分に使えない傾向が示されている
- 他の論文でも海外滞在中の学生の多くが、その環境をどう学習に活かすかを十分わかっていないと指摘している
- 話す力の伸びは、自習時間そのものより、どれだけL2文化およびその言語で人と関わったかに強く結びついていた
- 現地の人との友情の深さが高いほど、現地の言葉の伸びが大きいとされている
- 逆に母国の家族や友人との結びつきが強いままだと、現地で強いSocial Networkを作れず、言語面でマイナスに働くという先行研究もある
- ここで重要なのは、だから自習や授業は意味がないという結論にはならないということ
- 留学中の伸びを強く説明したのは、留学前の学習量であった
- 事前知識が多い学習者ほど、口頭能力でも伸びやすいとされてい
- つまり、自習や授業は「主役」ではないことが多いが、強い土台・加速装置にはなりうる
- 一方で「自習時間を増やせばそれだけで伸びる」という単純図式は危ないことも示している
- 最も研究に見合う見方は、「自習か交流か」ではなく、「自習で準備し、交流で言語を実践化する」になる
- 少なくとも、現地に住んでいても他人とほぼ交流せず、自習だけで十分という結論を強く支持する研究は見当たらなかった

# 地位社会との交流戦略

- 大学・会社・ボランティアのどれが良いかというより、その場がどんな構造になっているか、の方が大事
- 研究によると効きやすいのは、「同じ人と繰り返し会う」「何かを一緒にやる」「英語がその場の実用言語になっている」「少しずつ関係が深まる」ような場
- 逆に「単発の交流」や「行ってもあまり話さなくて済む場」は弱い
- 毎日、数時間の自習はかなり強い土台になる
- しかし、「英語が必要になる週単位の反復的な社会参加」、がないと、海外にいても口頭能力が伸びにくいという結果は一貫している
- 「現地との繋がり」＝ネイティブの友達だけではない
- 非ネイティブ同士でも目標言語が日常として回っている集団は伸びやすい
- 相手が「カナダ生まれの英語ネイティブ」でなくても、英語を本気で使う共同体なら十分有効
- ボランティアが最も研究と相性が良い活動
- カナダなどの移民は教室外で自分の母語を共有しない地元の人と話す機会を非常に有用だと感じていた
- ボランティが強いのは、受付・説明・連携・手伝い・段取りのように、言語が仕事として必要になるから
- 会社や大学でも、ただ作業をこなすだけだと学習機会として十分に使われないと示されている
- 同じ国の学習者同士で母語や英語以外に逃げやすい環境だと必ずしも強くならない
- つまり重要なのは「週次で同じ人たちと英語で何かを達成する場」
- 月に1回会う英語友達はゼロよりはずっと良いものの、研究でいう密な日常ネットワークにはまだなりにくい
- 伸びを分けるのは接触の有無より、頻度・親しさ・役割の継続性
- 自習だけで伸びづらいのは、言語の中に相互作用でしか鍛えにくい部分があるから
- 言語学習において、Interactionは不可欠な要素だと述べられている
- これは単に「聞く量」ではなく、相手に聞き返す・言い直す・意味を調整する・会話の順番を取る・相手の反応を見て説明を変える、という力
- 自習で語彙や文法は蓄積できるが、相手に合わせてその場で組み立て直す力は、やはり会話の中で育ちやすい
- さらに自習は実社会で拾ったものを学習対象にしないと効率が落ちる
- 職場や学校で英語を使う機会が多い場でも、学習者がただタスクをこなし、そこで起きた相互作業を振り返ったり評価したりする支援がないと、その環境の学習機会は生かされないと述べられている
- 逆に言えば、自習は無駄なのではなく、社会的経験を材料にしたときに強くなる
- 自習だけを増やしても、それが実使用につながらなければ伸びは保証されない

# 30歳という年齢

- 研究によると、30歳は英語力向上の「致命的な問題」でない
- 特に、仕事・生活・友人関係で使えるレベルまで伸ばすという意味では、今からでも十分現実的
- 40歳以降に移住した学習者を負った研究でも、年齢それ自体は進歩の信頼できる予測因子ではなく、到着時の英語力・英語を使う機会・教育歴が大きく関わっていた
- 区別をつけるなら「かなり上達する」と「ネイティブ同然になる」は別だということ
- 大規模研究では、文法学習能力は17.4歳ごろまで比較的保たれて、その後は徐々に低下すると推測されている
- 発音・言葉の自然さ・自動化の一部では年齢差が残りやすい一方、成人でも大きく伸びる部分はかなりある
- 年齢だけで悲観する必要はなく、他の研究でも、留学による絶対的なgainでは、大人が子供を上回ったという結果もある
- 30歳という年齢よりも、今の生活が英語を必要とする構造になっているかの方が、実際の伸びには影響する
- 一方で年齢による壁というよりも、成人期にカナダへ来た移民は、close friends の面では大きな不利が確認されなかった一方で、acquaintances は少なく、友人との対面接触頻度も低い傾向があった
- つまり、成人移住では「友達が1人も作れない」わけではないけれど、弱い ties や日常の接触頻度が細りやすいので、それが英語使用機会を減らしやすい、という読み方ができる
- 逆に、仕事・地域活動・友人関係で週単位の反復接触が増えるなら、30歳でもかなり伸びるというのが、研究からは1番自然な結論

# B1-B2→C1-C2の壁

- ネイティブが自然速度で話すと一気に分からなくなるのはB1B2レベルの学習者にとって典型的な現象
- この壁は主に知識不足というより、音声処理の自動化・語彙の深さ・会話での推測力・相互作業経験の差によるもの
- CEFRの定義そのものが、その差をかなりはっきり示している
- B2では、個人的・社会的・仕事・学業で普通に出会う標準的な話し言葉は理解できるが、極端な背景雑音、弱い談話構造、強いイディオム性があると理解が落ちやすいとされている
- C1になると、抽象的で複雑な話題の長い発話を追え、イディオムや口語表現の幅広い理解、明示されていない関係の把握が求められる
- C2では、速いネイティブ速度の話し言葉も、アクセントに慣れる時間が少しあれば理解できるレベル
- つまり、B2とC1/C2の差は「もっと難しい単語を知っている」だけではなく、速くて崩れた、含みの多い会話をリアルタイムで追えるか
- 研究で一番大きい差として出やすいのは、一般的な認知要因よりも、「語の音形・意味・使い方を速く安定して処理する力」だった
- つまり、宣言的に知っていることより、自動化された音声語彙知識の伸びの方が、リスニング向上と結びついていた
- 次に大きいのが、弱形・音の脱落・連結などを理解して、単語境界を見つけやすいかどうか、それがその後の文法・意味の推測に使える手がかりを与える
- 別の介入研究でもreduced formsを明示的に学んだ中級学習者はリスニング理解で良い結果を出した
- さらにC1C2よりの会話では、語彙の量だけでなく、語彙の深さ・塊としての言語が重要
- 語彙認知の幅と深さはリスニング成績と有意に結びつく
- まとまり表現の蓄積が流暢さや理解のギャップを埋める上で重要とされている
- もう一つB2から先で差がつきやすいのが推測しながら聞く力
- CEFRでもC1は文脈・語彙・文法手がかりを使って話しての態度・気分・意図を推測し、次に来る内容を予測するレベルとされている
- B2あたりでは「単語は知っているのに、全体の温度感・話の流れが取りきれない」が起きやすく、C1C2はそこがかなり違う
- 研究からの1番自然な推測は、B1B2付近でスタックしている要因として、ローカル社会とのinteractionの薄さはかなり大きい原因の一つ
- けれど、より正確に言うなら、それは上流の原因で、直接の詰まりは、 (1) 自動化されていない音声語彙、(2) reduced forms への弱さ, (3) 長い自然会話を追う処理速度不足 だと思われる
- 海外に住むことの利点は「知識が増える」より、「知っているものを速く回せるようになる」ところに出やすい
- そして、その processing speed を育てやすいのが、まさに反復的な対人接触
- interaction はSLAの不可欠な要素で、input・negotiation for meaning・output が発達に関わると整理されている
- 研究でも、留学者のL2伸びは social network pattern に有意に左右され、意味のあるホスト社会との関与が鍵だった
- 自習は強いが、英語が必要になる関係が薄い」場合、知識が会話能力へ変わる回数が少なくなる
- 海外に住みながら、自習を十分にこなし、B1B2付近でスタックしている場合、ローカル社会とのinteractionの薄さは大きな原因
- ただし、研究的にはそれをもう一段分解して、「interaction が薄い → 自然速度の音声への曝露が足りない → reduced forms と語境界処理が鍛えられない → 音声語彙の自動化が進みにくい → B1/B2感覚で止まりやすい」と考えるのが一番しっくりくる

# 非ネイティブとの会話

- 「相手がネイティブでないと英語は伸びない」とは言えない
- むしろ、非ネイティブ同士のやり取りでは、意味が通じない時の確認・言い換え・聞き返しが起きやすく、そうしたnegotiation of meaningは学習に重要だと考えられている
- 研究では、peer interaction は学習に必要なinputを得る「良い場」で、処理時間が長めに取れ、言語を試す機会が増えると整理されている
- peer interaction だけでも fluency は伸び、peer corrective feedback を訓練した群では accuracy と fluency の両方が伸びた
- しかも、受ける側だけでなく、与える側も伸びうる
- 相手の誤りに気づいて修正しようとすることで、自分の中の文法や表現のモニタリングも強くなることが示されている
- 非ネイティブのインプットは文法・語彙・語用論の面で弱い可能性を認めつつ、実際にはそのフリより、L2を多く使う利点の方が上回ったと解釈している
- また、非ネイティブ同士のinteractionは間違いに寛容で、ストsレスが少なく、英語を使う安全な場として語れている
- またより上手いL2話者はrole model と見なされ、そうした相手との会話は自分の gap noticing に役立つと報告されている
- ただし、ここにははっきりした限界があり、非ネイティブ同士で特に伸びやすいのは、fluency、自動化、言い換え、意味交渉、会話ストラテジー
- 一方で、grammar accuracy や pronunciationには弱いとされている
- もう一つ大事なのは、ネイティブかどうかより、相手の英語力と関係の質
- 学習成果を左右したのは proficiency 差そのものより、どれだけ collaborative にやりとりしたかだと整理されている
- さらに、L2-L2 ペアより、やや強い相手を含む mixed pair のほうが、focus on form がより target-like に解決され、ターゲット言語での発話量も多かった
- だから、少し自分より上手い nonnative speaker は、かなり良い相手になり得る

# Beliefsと同国コミュニティ

- まずは英語に対するbeliefsについて、「文法・ノート・教科書・間違い訂正」を重視するAnalytic Learning と「人と話す・英語圏で暮らす・英語を外で使う」のExperiential Learningよりも、「英語を話しても緊張しすぎない」「間違いを気にしない」「自分は進歩している」といった自己効力感や自信を持つSelf-Efficacy and Confidenceタイプが最も変化が大きかった
- 特に大きく変わったのは「英語を話しても緊張しすぎずにいられる」「話すときに間違いをしても大丈夫だと思える」「話すときに間違いをしても大丈夫だと思える」という項目
- この研究の核心は、留学の最大の成果は、すぐ点数に現れる能力差というより、英語を使うことへの心理的な壁が下がったことかもしれない、ということ
- ここも重要だが、自信が上がったからすぐに英語のテストの点数が上がるわけではないこと
- 1つTOEFLは主に読む・聞く・文法のテストで、話す場面での自信をうまく拾っていない可能性
- もう1つはbeliefが変わっても、それが実際の行動変化に変わるまで時間がかかる可能性があること
- また、研究を雑に読むと「前向きになれば伸びる」と見えるが、そこまでは言えない
- 正確にいうと、心理面が効くのは行動の入り口だから
- 例えば、「間違えるの怖い」「ネイティブ相手だと萎縮する」「うまく言えない自分を見せたくない」という状態だと、そもそも会話に入る回数が減る
- 逆に、自信が少しつくと、聞き返す、言い換える、雑談を伸ばす、といった行動が起こりやすくなる
- 後続のレビューでは、この心理面は単純ではないことも示されていて、留学は自信を高める一方で、ネイティブ話者との接触がかえって自信を下げる場合もある
- 例えば、留学初期には「思ったより話せない」と気づいて、自身が落ち、その後に回復する例も報告されている
- つまり心理面は「高ければ高いほど良い」というより、現実とのギャップをどう処理するかに関わるものだとみるが方が正確
- オーストラリアの台湾人留学生を調べた研究では、初期に仕事探し・生活の立ち上げ・感情的な支えのために、同じ台湾人・中国語圏のネットワークに強く依存するようになった
- これは最初の適応段階では重要な支えだと認めつつ、その依存が排他的に続くと、現地社会への適応を妨げるとされている
- 英語が十分でないために、自信を持てず、誤解が起きるのを避け、言いたいことを途中で諦めて、職場や接客で緊張する、という経験が重なり、その結果、現地の人とのやりとりを自分で減らしていくようになる
- これをvicious cycleと呼ぶ
- 大事なのは「同国人が悪い」ではなく、「排他的に閉じることが危ない」ということ
- 同国人ネットワークは海外生活では重要としつつ、問題なのはそれがずっとexclusiveになってしまうこと
- 「同国人コミュニティを持つな」ではなく、「それだけで生活が完結すると、英語とローカルの規範に触れる機会が減る」という話
- 率直な読みとしては、心理面は重要、でも「気持ち」だけでは足りない、前向きさや自信は、あくまで英語使用に踏み出すための条件であって、伸びそのものではない

# 自分の行動への落とし込み

# 自分が気づいていなかった認識

- まず、自分は「主役」だと思っていた自習が実は主役ではなかった
- 地域社会との繋がりをそこまで重要視していなかった
- 先週の振り返りおよび研究論文を鑑みると、地位社会との密接な繋がりこそが海外生活においては、主役であり、それが1番の英語力向上の鍵である
- 地域社会との密接で定期的な繋がりがないと今の自分の英語力は伸びないと仮定できる
- 例えば、小学生のときに、野球チームに入らずに自分だけで野球が上手くなるのはほぼ不可能である、野球チームに入っている子供の方が何倍も上手いし、さらに野球チームで練習しながら自分でも練習する子供が1番上手くなる
- 自習で全てを使い果たして、実践が出来なくなるのは本末転倒である
- 自習は重要な土台であり、アクション指標になり得るが、それ自体が目的になってはいけない
- 例えば、実践がある日は自習は1時間半にするなど、工夫が出来る

# 行動の改善

- どういう社会的繋がりが考えられるのか、自分に必要なものを言語化する
- 社会的繋がりには、大きく分けて、ワーク環境とプライベート環境があると推測
- ワーク環境
  - 重要なポイント
    - 同じ人と繰り返し会う
    - 何かを一緒にやる
    - 英語がその場の実用言語になっている
    - 少しづつ関係が深まる構造になっている
    - 自分が歓迎されている
    - 自分に責任感がある状態になっている
    - 自分が話さないといけない状態になっている
    - 自分の体調が良い
  - ワーク環境で大事なのは、自分がどれだけ、適度な緊張感を持ちつつも、心理的安全性を感じて、自分がハンドルしやすい、もしくは主役になりやすい環境になっているかどうか
  - 今のボアランティアが一つの候補であるが、自分の裁量が少ないような気もする、その結果、あまり話さなくても良い環境になっている
  - ワンオペとまでは言わないが、スタッフが少なくて、自分の裁量が大きい環境の方が良い
  - 環境は自分でコントロールできるというより、その職場と同僚に依存する部分があるので、良いところを見つけるまで、色々なとこにアプライしてみた方が良い
  - このボランティア環境が日常の地域社会とのinteractになる可能性がかなり高いので、ある意味で、最もリソースを投下する活動
  - とにかくボランティアにアプライし続けて、最適な場所を探すアクションをする
- プライベート環境
  - 研究でも述べられていた通り、非ネイティブ同士でも話し合う環境でも効果的
  - ただし、表面的な関係ではなく、深い関係にならないといけない
  - 月に1回、たまに会うような関係は、ゼロよりはマシだが、お互いの言語を伸ばす深い関係とは言えない
  - 毎週会うぐらい密な方が良い
  - ミートアップは単発イベントなので、それ自体は効果は高くないが、それから仲良くなれる人を見つけられたら、それは意味がある
  - ミートアップもしくは新しい人に会いに行くアクションを継続的にした方が良い
  - それが密な英語コミュニケーションを生むキッカケになる可能性がある
- ボランティアへのアプライ・新しい英語スピーカーに会いに行くアクションの強度を高める
  - ボランティアについては、既に2件アプライしたものの、返事がないので新しくボランティアを探す
  - ミートアップもしくは英語スピーカーとの交流は最低週1回を目標に実施するようにする
