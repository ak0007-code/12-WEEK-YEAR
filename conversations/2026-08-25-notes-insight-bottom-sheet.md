# Notes / Insightメニューのボトムシート化

## User

Webページで、NotesとInsightを押したらページ内にドロップダウンなどでリストを出し、Englishなどの項目を押したら新しいページに飛ぶようにできる？

## AI

トップページ（docs/index.html）のNotes / Insightボタンをドロップダウン化した。ボタンを押すとその場にリスト（Notes：人間性・英語学習の方向性、Insight：English・Health・Work・Humanity）が開き、項目を押すと `library.html?type=<種別>&id=<項目>` に直接遷移する。リストは `note-core.mjs` のNOTES / INSIGHTS定義から生成するため、項目を追加すればメニューにも自動反映される。

## User

ドロップダウンじゃなくてもモーダルとかでも良い。デザイン的に良い方で。

## AI

スマホ前提の画面なので、ドロップダウンよりボトムシート型モーダルの方がタップしやすくデザインの馴染みも良いと判断し、切り替えた。ボタンを押すと背景が暗くなり、下からシートがスライドインしてカード型のリストが出る。閉じ方は背景タップ・×ボタン・Escapeの3通りで、シート表示中は背面スクロールをロックし、セーフエリア分の余白も確保している。Chromiumで開閉・遷移・クローズ動作を確認済み。

## User

常にサーバー上でmainにマージしてmainにプッシュするルールにしていたはず。

## AI

CLAUDE.mdのルールに従い、作業ブランチをmainにマージしてプッシュした。あわせて古くなっていた `scripts/mobile-layout.test.mjs` の2件（スタイルシートのバージョン、Notes / Insightがリンクである前提のテスト）をボトムシート版の実装に合わせて更新し、全41テストが通ることを確認した。
