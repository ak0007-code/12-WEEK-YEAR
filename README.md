## 全体戦略

- 4週間ごとに前半・中盤・後半で区切る
  - アクションスケジュールは前半・中盤・後半の4週間ごとにプランニングする
  - 週末、必要に応じてアクション内容を微調整する
  - 大局を見れば4週間ごとに戦い方が変わる可能性が高い
  - アクション履歴と結果を見て戦い方を変える
  - 4週間の間は一貫したアクションを継続した方が良い
- 気分ではなくコミットメントに拘る
  - 責任を持ち、結果に拘り、アクションにコミットする
- Aspirational VisionとActionの間にDeep Thinkを挟む
  - Aspirational Visionを思い出し、それを達成するためのアクションと戦略をDeep Thinkする
  - Daily:その日のプランニング
  - Weekly:週全体の振り返り・来週へのプランニング
  - Deep Thinkにリソースを使うこと、適当にやってはいけない
  - プランで出てこないことはアクションできない
  - 何をやらないといけないか？何が上手くいっていないか？何を改善したら結果が良くなるか？なぜそのアクションが出来ていないのか？
  - Deep Thinkの後はアクションに拘る
- 毎日カレンダーを確認する
  - 時間というのは最も貴重であり、軽視されがちな有限リソースである
  - 全ての結果は時間が姿を変えたもの
  - 自分が今どこにいるのか、自分にはどれくらい時間が残されているのかを毎日確認する
- コミットとホワイトスペースのバランス
  - 脳というのはホワイトスペースを意図的に作らないと振り返りや新しい考えが入るスペースがなくなってくる
  - 平日と土日のように明確に区切る必要はないが、ホワイトスペースを作ることを忘れない

##### 方針

###### 英語

- 全ての中で英語を最優先にする。英語を伸ばすことを目標にしている以上、最優先でないと矛盾する
  - Week 3は金〜日に英語だけを最優先にし、リスニングとスピーキングが上がった。
  - Week 4は最優先を週末だけでなく毎日続け、それでも点数が保てるか、上がるかを確かめる
  - 英語を最優先にできているかはチェックリストでは測りにくいので、週次の振り返りで確かめる
- 英語はやりすぎればやりすぎるほど良い
- ポイントを毎日意識する
  - Aspirational Visionを確認する。思い出すときは自分の現在地も同時に認識する
  - Attention Resourceを英語に集める
  - 毎日英語が向上していることを確認する
  - 英語とコネクトする
- 英語の環境整備（アプリや英語話者との会話）にリソースとアテンションを割く
- PodTextはアクションから外す。計測自体が英語力の向上と関係がなかった
- 計測指標
  - CELPIPリスニング
  - CELPIPスピーキング（Speechaceの点数はIELTS換算。6.5〜6.9でCELPIP 8、7.0以上でCELPIP 9に相当）
  - 疲労度（HelloTalkで1時間以上話した直後に測る）

- xyz仮説
  - PodTextを手段にした仮説はWeek 3で終えた。中盤（Week 5〜8）の計画で、英語を最優先にすることを軸に立て直す

###### 仕事

- 仕事は月・火が勝負。ここで軌道に乗らないと、週の後半に良い結果はついてこない
- 最初にやることを書き出す、プランニングできないとアクションはできない
- できれば月〜木で仕事を終わらせ、金〜日は英語だけにする
  - Week 3は金〜日に英語だけを最優先にして、リスニングとスピーキングが上がった
  - 9時までに仕事を終えるアクションは、月〜木に合わせて週4回にする
- 開始と終了の時間を守る
  - 午前と昼は英語以外やらない
  - 9時に仕事を終えたら、衝動的に仕事を再開しない。Week 3の火曜は仕事を再開して、リラックスモードに入れなかった
- AIビデオで複数アカウントから読者を集める検証は終えた
  - jpnbabyteachersはKoemojiの初期の宣伝の場として使う。コンテンツ制作は自分のリソースがかからないので続ける
- AmpliumのVRコンサート事業は、日本市場で黒字を出すのは難しいと結論した。イマーシブジャーニー事業のデータを集め、次のアクションを決める
- 一週間で達成するアクションを決めて、それを達成するように動く。プランに書き出せないアクションは実行できない
- xyz仮説はBizDevで管理する

###### 健康

- 衝動的な行動をせず、毎日同じルーティンで過ごす。例外を作らず、決断する機会を極力なくす
  - Week 3は夜のルーティンが崩れなかった水・木に、9時終了・お風呂・リラックスモード・睡眠スコアが全部そろい、7時間30分と7時間21分眠れた（睡眠スコアは80点台後半）
  - 火曜は9時に仕事を終えた後、衝動的にまた仕事をしてしまい、リラックスモードに入れなかった
  - 衝動的に夜にご飯を食べたり夜更かししたりしてルーティンを崩すと、そのツケを払う方がしんどい
- 結果につながるマインドとアクションは、感情と切り離して考える。感情だけで考えると、常に自分が楽な方を選ぶことになる
- 睡眠スコアは3週続けて火・木・金の3晩を測れていない。火・木・金はApple Watchを付けて寝る
- 0時ぎりぎりに寝ると睡眠スコアのinterruptionsが上がらない。23時過ぎには歯磨きを終えてイヤホンを付け、23時半には寝始める
  - 湿度が低く喉が痛いので加湿器を付ける。寒いので上着を着る
- 顔チェックは週1回にする

- xyz仮説（Week 4で判定する）
  - 23時までにイヤホンを付けてリラックスモードに入る日を週4日以上作ると、Week 4（10/25）までに、Apple Watchで測った寝つく時刻が0時より前になり、火・木・金の3晩とも7時間以上眠れる
    - Week 3はリラックスモードに入れた水・木に、7時間以上眠れた
  - 外れたときの判断
    - リラックスモードには入れたのに、寝つく時刻が0時を過ぎる：イヤホンを付けた後の過ごし方（Netflixなど）を見直す
    - 0時前に寝つけているのに、7時間に届かない：朝の予定を見直す
    - リラックスモードに入れない：仕事が21時までに終わっていないか、夜に別の予定が入っているか、仕事を終えた後に衝動的に仕事などを始めている。仕事の計画、夜の予定、夜のルーティンを見直す

  - Attention Resourceを英語に集める

  - 次のCELPIPはPart6まで解き、点数を正確に数える。語彙ではなく、設問への答え方や記憶の保持が原因かを切り分ける

  - CELPIPリスニング
  - CELPIPスピーキング（Speechaceの点数はIELTS換算。6.5〜6.9でCELPIP 8、7.0以上でCELPIP 9に相当）

    - Week 2は98.2%（CELPIP37 Part6、440語中8語ミス）と96.4%（CELPIP39 Part4、278語中10語ミス）で、上がったとは言えない
  - 外れたときの判断
    - PodTextの理解率は上がったのに、CELPIPのリスニングと疲労度が届かない：弱点は語彙だけではないと判断し、聞き取りなど他の原因を探す
    - PodTextの理解率が上がらない：語彙の増やし方に問題があると判断し、学習方法を見直す
    - 実行率が85%未満だった：プランの前に実行を立て直す
